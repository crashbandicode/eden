# AI and LLM usage (fork policy)

This fork permits AI and LLM-assisted work on code, documentation, commit messages, debugging, and research.

You remain responsible for reviewing, testing, and understanding anything you submit.

Keep the project's quality bar: builds and tests pass, changes match surrounding style, and commit messages are concise and written for a human reader. Avoid decorative unicode (for example em-dashes and arrows) in code and commit messages.

Upstream Eden (https://git.eden-emu.dev) prohibits AI and LLM use. Contributions intended for upstream must follow upstream's rules and be rewritten by a human before submission.
